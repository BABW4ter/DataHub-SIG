# DataHub SIG V0.5
Nouveau workflow hebdomadaire le mercredi et déclenchement manuel.
- API Géo : communes GeoJSON (population incluse).
- Géorisques GASPAR : interrogation des risques par code INSEE, données brutes et erreurs individuelles conservées.
- IGN Géoplateforme WFS : récupération des noms de couches via GetCapabilities. **Aucune géométrie IGN téléchargée à ce stade**.
- Résumé lisible dans GitHub Actions et artifact avec rapport JSON/CSV.

Limites : une exécution verte signifie qu'au moins une source a fonctionné. Lire le rapport pour les échecs partiels. Les fichiers expirent après 30 jours. Les services peuvent limiter le débit ou changer leurs paramètres. Ce workflow n'est pas une preuve de moissonnage exhaustif du Val-d'Oise. Pour les données IGN volumineuses, prévoir un téléchargement par produit et un stockage durable externe.
